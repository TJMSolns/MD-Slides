# MS-032 evidence: inline markdown in table cells, quotes in captions (v1.1.2)

- **Defects (found building the short-course deck, 2026-10-21):** `| the **highest** of the inputs |` rendered
  "thehighestof the inputs"; a cell that was only `**Buy**` rendered without bold; `caption: ... the word "chocolate"`
  lost its closing quotation mark.
- **Fix:** table cells keep inline markdown (bold, code, links, spaces) in cells and headers (`FlexmarkAdapter`,
  `HTMLRenderer`); frontmatter values are unquoted only when the whole value is wrapped in quotes (`MarkdownParser`).
- **Tests:** `FlexmarkAdapterTableSpec`, `HTMLRendererTableSpec`, `FrontmatterQuoteSpec`.
- **Downstream:** the live demo at https://www.tjm.solutions/mdslides/demo (built from v1.1.2) shows `<strong>` and
  `<code>` inside `<td>`; the course deck in prof-writing restored its bold cells and quoted captions (`75590ca`).
